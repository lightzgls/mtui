MTUI v0.11.7 makes browsing, song selection, and queue editing more consistent, and removes repeated information from the player.

## Changes

- Click a song once to select it; double-click or press Enter to play it. Right-click selects the song and opens its actions across Home, Search, Artist, Library, Related, and Queue. Album and artist links and explicit playback controls keep their single-click behavior.
- Artist Top songs gains **Show more / Show less** and **Play all**. When YouTube supplies the full listing, Play all includes songs beyond the initial preview and ends after the last loaded song. Back restores the expanded list. Loading is bounded to 200 songs and eight continuation requests; incomplete listings and failed expansions remain visible and retryable.
- Fix upcoming-song reordering with mouse dragging and `Alt-Up` / `Alt-Down`, `Shift-Up` / `Shift-Down`, and `K` / `J`. The selected song visibly changes position without restarting playback. Queue editing stays in the song menu and shortcuts instead of a separate row of Up, Down, and Remove buttons.
- Use **Play next** and **Add to queue** consistently across song menus. Adding an existing upcoming song does not duplicate it; Play next promotes it directly after the current song.
- Click a linked artist name in playlist rows, Library songs and cards, or Related to open Artist. Links receive a subtle underline only when the complete artist name is visible. Back retains the selected item and scroll position.
- Click the current cover artwork to pause or resume. Precision volume still uses the mouse wheel over the artwork when enabled.
- Add **Settings → Appearance → Show key hints**, enabled by default and saved across launches. Hints adapt to available space, and hiding them keeps shortcuts active. Help retains the full keyboard reference.
- Add direct playback shortcuts outside text entry and dialogs: `Ctrl-L` for Like, `Ctrl-Y` for Share, `Ctrl-A` for Save to playlist, and `Ctrl-O` for audio output. Album and playlist pages also accept `a` for Play all.
- Improve search editing for Unicode and cursor movement, keep the originating page visible while editing, and discard results for abandoned drafts. Header Back and `Alt-Left` use the same navigation history as Esc.
- Remove repeated playing-song text, routine page totals, the upcoming-song count, duplicate volume feedback, and repeated Settings platform labels. Errors, action feedback, and paused/loading states remain visible.
- Fix artist and Home metadata parsing so play counts no longer appear as album names. Real album routes remain available when supplied by YouTube Music.

## Install or Upgrade

**Windows:** use **Settings → Updates**, or download `MTUI-0.11.7-Setup-x64.exe`. A single portable executable is also available. Updates preserve account data and preferences.

**Linux:** run as your normal user:

```sh
curl -fsSL https://github.com/lightzgls/mtui/releases/latest/download/install.sh | bash
```

Writable per-user Linux installations can also use **Settings → Updates**. System-managed Debian/Ubuntu installations should install the new `.deb`, version `0.11.7-1`. Prebuilt Linux packages require x86-64, glibc 2.34+, and compatible audio, TLS, D-Bus, and WebKitGTK runtimes.
