MTUI v0.11.1 restores the original lyrics experience.

- Remove the romaji provider, button, and shortcut introduced in v0.11.0.
- Restore the YouTube Music lyrics flow and LRCLIB synchronized-lyrics fallback. Formatting differences between sources no longer block the previous fallback behavior.
- Lyrics always open in the original view, with the existing follow and expanded-reading controls.

Validated on Windows with 591 passing isolated tests and strict Clippy checks.

Open **Settings → Updates** to install and restart. Installer and portable downloads are available below.
