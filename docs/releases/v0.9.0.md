MTUI v0.9.0 adds automatic sign-in maintenance and fixes playback, account actions, artwork memory use, and background request handling.

### Playback and sign-in

- Switching audio outputs resumes the actual audio at the saved position, including while paused. AAC packet boundaries no longer interrupt the resume skip while the progress bar continues ahead.
- Saved browser sessions renew automatically every 48 hours, including in the tray. Explicit authentication failures trigger earlier recovery, temporary failures retry quietly with persistent cooldowns, and Google verification opens the sign-in window when needed.
- Logout and newer sign-ins reject late helper results. Background renewal is bounded and leaves no browser running between attempts.
- Interrupted audio ranges retry without duplicating partial bytes; full responses to range requests no longer replay the beginning of a song.

### Reliability and resource use

- Improve playlist saves with the correct Liked Music operation, duplicate checks, explicit success acknowledgements, and verification of ambiguous responses.
- Separate account actions from browsing requests, cancel obsolete reads, and bound artwork queues and response sizes.
- Reject oversized JPEGs before decoding, reduce artwork allocation, and fix cover-colour accumulation.
- Save settings atomically and debounce volume updates. Distinguish expired sessions, permissions, rate limits, and provider failures in account errors.

### Downloads

- **MTUI-0.9.0-Setup-x64.exe** — per-user Windows installer.
- **MTUI-0.9.0-windows-x64-portable.exe** — single-file portable app, with sign-in and console hosting built in.

Fully exit MTUI from the tray before replacing the portable executable. Existing preferences and the saved browser profile are retained. Google can still require interactive verification; automatic renewal does not override account revocation. Playlist-save regressions use fixtures, and account reads and sign-in were checked live without adding or removing music.

Validated with 510 default workspace tests, a real AAC sample comparison, strict Clippy checks, and a hidden sign-in smoke test. See [bug-fix details](https://github.com/lightzgls/mtui/blob/v0.9.0/docs/bug-fixes.md).
