MTUI v0.11.3 fixes cover-art cropping and Discord artwork changes.

- Preserve the complete square album sleeve, including dark borders and edge text. Padding removal no longer shifts or crops native artwork in the player or card tiles.
- Discord uses only native YouTube Music artwork and waits for it instead of briefly showing a YouTube video thumbnail. A terminal image fallback no longer replaces Discord's Music artwork.

Validated on Windows with 598 passing isolated tests and strict Clippy checks.

Open **Settings → Updates** to install and restart. Installer and portable downloads are available below.
