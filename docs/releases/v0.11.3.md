MTUI v0.11.3 fixes cover-art cropping and Discord artwork changes, and now includes prebuilt Linux downloads.

- Preserve the complete square album sleeve, including dark borders and edge text. Padding removal no longer shifts or crops native artwork in the player or card tiles.
- Discord uses only native YouTube Music artwork and waits for it instead of briefly showing a YouTube video thumbnail. A terminal image fallback no longer replaces Discord's Music artwork.
- Linux x64 downloads include both the player and the YouTube Music sign-in helper. The Debian/Ubuntu package lets APT install missing runtime libraries; no Rust, compiler, or development packages are required.
- One-command Linux installation detects Debian/Ubuntu, Fedora, Arch, and openSUSE and installs missing runtime libraries. The player and sign-in helper are installed for the current user.
- Linux in-app updates work across compatible distributions for writable installations, verify and replace both executables, and restart in the same terminal. System-managed packages still update through their package manager.
- Settings display platform support on Windows and Linux. Playback, appearance, and Discord work on both; only tray controls remain Windows-only. Updates work on Windows and Linux, not macOS.

This release's binaries were refreshed on 13 October 2026 to include the Linux installer, Linux in-app updates, and platform labels. The original release tag is unchanged; the [refreshed build source is 843c479](https://github.com/lightzgls/mtui/commit/843c479eaa4e09248c969a6fb26a2cff0c3fc506). These changes are also available as the separate [v0.11.4 release](https://github.com/lightzgls/mtui/releases/tag/v0.11.4), which existing Windows copies can receive through the updater.

Validated on Windows with 601 passing isolated tests and Linux with 585 passing tests, plus strict Clippy checks on both.

Linux packages were built on Ubuntu 22.04. Installation, sign-in-helper loading, and updater replacement were checked in Ubuntu 24.04, Fedora 44, Arch, and openSUSE Tumbleweed containers, without installing Rust or a compiler. Interactive Google login and hardware audio were not exercised in these headless containers. The `.deb` is about 1.5 MB and the curl installer's archive about 2.1 MB; MTUI plus first-launch tools is about 103 MB via `.deb` or 104 MB via curl on an Ubuntu Desktop that already includes the required libraries, excluding package metadata and network overhead. Other systems may need additional libraries; Arch may also propose system updates when resolving missing dependencies.

**Windows:** earlier versions can upgrade through **Settings → Updates**. Already on v0.11.3? Run the refreshed installer below again, or replace the portable executable, to receive the new settings labels. An equal-version refresh is not offered by the in-app updater.

**Linux (x64):** run as your normal user:

```sh
curl -fsSL https://github.com/lightzgls/mtui/releases/latest/download/install.sh | bash
```

Open MTUI from the application menu or use the command printed by the installer. Future updates are available under **Settings → Updates**. Prebuilt binaries require x86-64 and glibc 2.34+; Alpine/musl and ARM need separate builds. Older v0.11.3 copies need this refreshed build installed once to get Linux in-app updates.

The `.deb` and `.tar.gz` archive are also available for manual installation. See the [installation guide](https://github.com/lightzgls/mtui/blob/main/docs/usage.md#installation), including script inspection and system-managed installation. `SHA256SUMS` covers the Windows and Linux downloads and `install.sh`.
