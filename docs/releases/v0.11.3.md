MTUI v0.11.3 fixes cover-art cropping and Discord artwork changes, and now includes prebuilt Linux downloads.

- Preserve the complete square album sleeve, including dark borders and edge text. Padding removal no longer shifts or crops native artwork in the player or card tiles.
- Discord uses only native YouTube Music artwork and waits for it instead of briefly showing a YouTube video thumbnail. A terminal image fallback no longer replaces Discord's Music artwork.
- Linux x64 downloads include both the player and the YouTube Music sign-in helper. The Debian/Ubuntu package lets APT install missing runtime libraries; no Rust, compiler, or development packages are required.

Validated on Windows with 598 passing isolated tests and strict Clippy checks.

Linux packages were built on Ubuntu 22.04 and installed successfully in a fresh Ubuntu 24.04 container. Both package formats include a runnable sign-in helper. The `.deb` is about 1.5 MB; MTUI plus first-launch tools is about 103 MB on an Ubuntu Desktop that already includes the required libraries, excluding package metadata and network overhead.

**Windows:** open **Settings → Updates** to install and restart. Installer and portable downloads are available below.

**Linux (Debian/Ubuntu, x64):** download `MTUI-0.11.3-linux-x64.deb`, then run:

```sh
sudo apt install ./MTUI-0.11.3-linux-x64.deb
mtui
```

The `.tar.gz` archive is also available for manual installation. See the [installation guide](https://github.com/lightzgls/mtui/blob/main/docs/usage.md#installation). `SHA256SUMS` covers the Windows and Linux downloads.
