MTUI v0.11.10 fixes installation on Arch Linux and includes the changes since v0.11.8.

- **Install on Arch Linux.** The installer resolves the OpenSSL 3 libraries required by the prebuilt player even when Arch ships a newer OpenSSL version.
- **Create and edit YouTube Music playlists.** Create private playlists, rename playlists you own, and remove or reorder songs.
- **Revisit songs from Listening history.** Open **Library → History** to see your recent plays and play them again, even when signed out.
- **Play more reliably on slow connections.** Audio downloads can continue while data is still arriving.
- **See video artwork in Discord.** Rich Presence uses the video thumbnail when YouTube Music has no cover.
- **Share playback diagnostics.** **Menu → Copy diagnostics** copies version, platform, and playback error information.

Update from **Settings → Updates** on Windows and writable Linux installations. If you installed MTUI through a system package manager, update through that package manager.
