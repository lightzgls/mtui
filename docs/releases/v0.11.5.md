MTUI v0.11.5 adds Windows system media controls, Linux MPRIS integration, and consistent Linux terminal commands for launching and uninstalling the app.

## Changes

- Windows media controls publish the track, artist, playback state, position, and duration. Play, pause, next, previous, and seek use the same player and queue as the terminal. Explicit play/pause requests remain idempotent when several requests arrive together.
- The Windows media session uses a persistent top-level window owned by MTUI and the stable AppUserModelID `io.github.lightzgls.MTUI`. Closing the console to the tray or reopening it keeps the media session alive.
- Linux desktops can discover `org.mpris.MediaPlayer2.mtui` through MPRIS. Desktop widgets and media keys can read metadata and the timeline, control playback and seeking, and adjust volume. Stale seek requests for a previous track are ignored.
- Linux curl, archive, and source installation now register both `mtui` and `mtui-uninstall` and configure PATH for Bash, Zsh, Fish, and POSIX login shells. Open a new terminal after installation. Debian packages provide both commands in `/usr/bin`.
- Run `mtui-uninstall` as your normal user after closing MTUI to remove the app and **all local MTUI data**, including settings, saved sign-in sessions, browser profiles, history, logs, caches, update downloads, and downloaded playback tools. It preserves unrelated applications and shell settings. Native package removal uses APT, DNF, pacman, Zypper, RPM, or APK where applicable.
- Linux archives include an installer for local installation without downloading the archive again. Source builds use the same installation flow without the prebuilt x86-64/glibc restriction.

## Install or Upgrade

**Windows:** use **Settings → Updates**, or download `MTUI-0.11.5-Setup-x64.exe`. A single portable executable is also available. Upgrading preserves account data and preferences.

**Linux:** run as your normal user:

```sh
curl -fsSL https://github.com/lightzgls/mtui/releases/latest/download/install.sh | bash
```

Open a new terminal, then run `mtui` to launch the app or `mtui-uninstall` to uninstall it and erase its local data. User installations do not need administrator access; installing missing system libraries or removing a native package may require `sudo`.

Existing writable Linux installations can update playback and media integration through **Settings → Updates**. Run the installer once to add the new uninstall command and terminal PATH setup to an older installation. System-managed Debian/Ubuntu installations should update with the new `.deb`; its Debian version is `0.11.5-1`.

Prebuilt Linux downloads require **x86-64 and glibc 2.34+**, with compatible audio, TLS, D-Bus, and WebKitGTK runtimes. Other architectures/libcs need a compatible source build; the same source installer registers both terminal commands. Missing runtime setup is automatic for Debian/Ubuntu, Fedora, Arch/Manjaro, and openSUSE. Other distributions can use the installer with the runtimes supplied separately.

Validation includes isolated Windows/Linux workspace tests and strict Clippy, a native Windows media-session test, a private D-Bus MPRIS controller test, ShellCheck, 27 installer/uninstall scenarios, and Linux package inspection. Published builds additionally pass the release workflow's runtime-import and four-distribution container checks. Interactive Google login and hardware audio remain manual checks.
