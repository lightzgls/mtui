MTUI v0.8.1 expands YouTube Music browsing, adds account actions to the player, and improves the Windows window and artwork behavior.

### Browsing and interface

- Search songs, artists, albums, playlists, and videos with result-type filters.
- Browse more personalized Home shelves, saved playlists, album track lists, and artist catalogs. Open artist and album pages from available track links.
- Apply muted cover colors throughout the app and give queue entries more space with clearer title, artist, and duration columns.
- Refresh the README with real screenshots, an overview recording, and a user-provided resource-usage snapshot. Keep detailed instructions in the usage guide.

### Player and Windows

- Add Like, Share, Save to playlist, Shuffle, Repeat, and Output controls to the playback bar and Ctrl+P menu. Account writes show pending, confirmed, and failed states.
- Recover an opening HTTP 403 with a fresh stream URL and bypass failed cached URLs when retrying.
- Restore the existing Windows session when reopening the executable or shortcut.
- Lock native-window font zoom, update artwork geometry across monitor scaling changes, and reduce Home artwork flicker.

### Downloads

- **MTUI-0.8.1-Setup-x64.exe** — per-user Windows installer.
- **MTUI-0.8.1-windows-x64-portable.exe** — single-file portable app.

The README resource image shows 27.6 MB across two MTUI processes in one Task Manager capture; it is not a long-session benchmark. YouTube account history must be enabled for listening-history synchronization.
