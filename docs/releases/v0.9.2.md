MTUI v0.9.2 lets YouTube Music personalize radio queues using your saved session.

- Use the current signed-in session for the initial radio queue, additional pages, and fallback stations.
- Pick up session renewal or logout on the next queue request. Radio remains available anonymously when no saved session is present.
- Refresh the README and simplify documentation to the usage guide, testing guide, and release notes.

Validated with 531 passing default tests, strict Clippy checks, and live initial-queue and continuation checks in both signed-in and guest modes.

Downloads:

- **MTUI-0.9.2-Setup-x64.exe** — Windows installer.
- **MTUI-0.9.2-windows-x64-portable.exe** — single-file portable app.

Fully exit MTUI from the tray before upgrading or replacing the portable executable.
