MTUI v0.9.1 is a small update that fixes playback edge cases and cleans up the Windows window title.

- Show **MTUI** in the title bar instead of the executable's full path, including when reopening the window from the tray.
- Preserve progress-bar seeks made immediately after selecting a song, while its stream is still loading.
- Advance the queue correctly when seeking to the end of a song during buffering.
- Cancel pending queue pages when clearing upcoming songs, even when only the current song remains.
- Keep the newly selected song's listening state when an older song finishes after a new selection.

The update also adds an isolated test runner and a catalog of 94 test scenarios. Validation includes 531 passing default tests, 10 successful stress runs, two local AAC checks, strict Clippy checks, and two Windows console-title checks. Live account changes and long-session hardware tests remain separate from the default suite.

Downloads:

- **MTUI-0.9.1-Setup-x64.exe** — Windows installer.
- **MTUI-0.9.1-windows-x64-portable.exe** — single-file portable app.

Fully exit MTUI from the tray before replacing the portable executable.
