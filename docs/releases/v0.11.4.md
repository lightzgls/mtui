MTUI v0.11.4 makes Linux installation and updates easier, keeps sign-in included, and labels platform-specific settings.

## Changes

- Install prebuilt MTUI on Debian/Ubuntu, Fedora, Arch/Manjaro, and openSUSE with one command. The installer verifies the release checksum, installs both the player and sign-in helper for your user, and uses your package manager only when runtime libraries are missing. No Rust, compiler, or repository clone is required.
- Update writable Linux installations through **Settings → Updates**. MTUI verifies and stages both executables, checks their runtime compatibility, replaces them together, and restarts in the same terminal. Failed replacement or restart restores the old pair. System-owned packages continue to use their package manager.
- See **All platforms**, **Win + Linux**, or **Windows only** beside settings. Audio output, volume, artwork, and Discord work on Windows and Linux. Tray controls remain Windows-only; macOS does not yet have in-app updates.
- Windows downloads statically link the Visual C++ runtime and the WebView2 loader. Sign-in uses the operating system's WebView2 runtime, without a separate loader DLL or Visual C++ redistributable.
- Updated installation, download-size, settings-support, troubleshooting, testing, and release documentation. Linux archives and packages include the usage, testing, and release guides.
- Fixed ShellCheck annotations for the installer test mocks used indirectly by package-manager calls.

The installer and updater were previously added to refreshed v0.11.3 downloads. Publishing them as v0.11.4 gives existing Windows v0.11.3 users a normal in-app upgrade and ties the release tag to its complete source.

## Install or Upgrade

**Windows:** download `MTUI-0.11.4-Setup-x64.exe`, or use **Settings → Updates** on v0.10.0 and later. The per-user installer needs no administrator permission. A single portable executable is also available. Sessions, preferences, and downloaded playback tools are retained.

**Linux (x64):** run as your normal user, without sudo:

```sh
curl -fsSL https://github.com/lightzgls/mtui/releases/latest/download/install.sh | bash
```

Open the application-menu launcher or run the command printed by the installer. Refreshed per-user v0.11.3 installations can also update in-app. Original Linux v0.11.3 copies need the command above once to get update support. For system-managed Debian/Ubuntu installations, install the new `.deb` with APT; its Debian version is `0.11.4-1`.

Prebuilt Linux downloads require **x86-64 and glibc 2.34+**, plus compatible audio/TLS/WebKitGTK runtimes. Other glibc distributions can use the installer when those runtimes are present. ARM and Alpine/musl builds are not published. Immutable systems with missing libraries need the runtimes supplied separately or an installation inside Distrobox. Arch dependency installation uses a full `pacman -Syu` transaction; review proposed system updates before confirming.

The app download is approximately **3.4 MB** for the Windows installer, **1.5 MB** for the Linux `.deb`, or **2.1 MB** for the Linux archive, including sign-in. With first-launch playback tools, allow about **90 MB on Windows 11**, or **103 MB via .deb / 104 MB via curl on Ubuntu 24.04 Desktop** when system runtimes are already present. Other systems may need additional libraries. These are approximate download payloads, not installed disk sizes, and exclude package metadata, network overhead, and optional system updates.

`SHA256SUMS` covers both Windows downloads, both Linux packages, and `install.sh`. Release checks include workspace tests and strict Clippy, Windows runtime-import inspection, and fresh Linux container installation/sign-in-loader/updater checks on Ubuntu 24.04, Fedora 44, Arch, and openSUSE Tumbleweed. Headless tests do not verify interactive Google login or hardware audio.
